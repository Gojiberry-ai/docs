Example walkthroughs for jobs people do with the API and the [MCP server](/mcp-server). Each one is a sketch: copy the calls, swap in your own ids, and adapt the flow. Every step also names the MCP tool your AI assistant uses for it.

You need an API key from **Settings → API**. Send it as `Authorization: Bearer YOUR_API_KEY` to `https://ext.gojiberry.ai`. Authentication and rate limits are on the [Quickstart](/quickstart).
