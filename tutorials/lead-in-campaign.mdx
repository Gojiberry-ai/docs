Example. Look up a person, then read their progress through the campaign that uses their list.

<Steps>
  <Step title="Find the contact">
    ```bash
    curl -H "Authorization: Bearer YOUR_API_KEY" \
      "https://ext.gojiberry.ai/v1/contact?search=jane%40acme.com"
    ```

    Open the match with `GET /v1/contact/{id}`. On that contact, `listId` is the list they belong to, `readyForCampaign` says they are accepted for outreach, and `campaignStatus` lists the steps already completed. Each `stepNumber` matches a step on the campaign.
  </Step>
  <Step title="Find the campaign on that list">
    ```bash
    curl -H "Authorization: Bearer YOUR_API_KEY" \
      https://ext.gojiberry.ai/v1/campaign
    ```

    Use the campaign whose `listIds` include the contact's `listId`.
  </Step>
  <Step title="Read what the campaign already did">
    ```bash
    curl -H "Authorization: Bearer YOUR_API_KEY" \
      "https://ext.gojiberry.ai/v1/campaign/CAMPAIGN_ID/logs?limit=50"
    ```

    Each log row is one action (invitation, message, email, reply, and so on) on a contact. Filter the rows by the contact id you looked up.

    See [Get a contact](/api-reference/contacts/get-a-contact), [List campaigns](/api-reference/campaigns/list-campaigns), and [Logs](/api-reference/campaigns/logs).
  </Step>
</Steps>
