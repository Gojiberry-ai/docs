Example. Website visitors arrive as contacts on a list. The API starts the source agent; the tracking snippet itself is installed from the app.

<Steps>
  <Step title="Create the list the visitors will land in">
    ```bash
    curl -X POST -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name":"Website visitors"}' \
      https://ext.gojiberry.ai/v1/list
    ```

    Save the list `id`.
  </Step>
  <Step title="Create a website-visitor source agent">
    Pass `agentType` as `website-visitor` and the `listId` from the previous step. Do not send a `WEBSITE_VISITOR` variable yourself.

    ```bash
    curl -X POST -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name":"Website visitors","agentType":"website-visitor","listId":LIST_ID}' \
      https://ext.gojiberry.ai/v1/agent
    ```
  </Step>
  <Step title="Read the contacts on that list">
    Identified visitors show up as contacts. Filter by the same list.

    ```bash
    curl -H "Authorization: Bearer YOUR_API_KEY" \
      "https://ext.gojiberry.ai/v1/contact?listId=LIST_ID"
    ```

    See [Create a source agent](/api-reference/agents/create-a-source-agent) and [List contacts](/api-reference/contacts/list-contacts).
  </Step>
</Steps>
